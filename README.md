# Sana & Rizwan — Wedding Invitation

A lightweight, mobile-first wedding invitation site. Open `index.html` in a browser or deploy this folder as a static site.

## Editable details

Update the `weddingConfig` object in the script near the end of `index.html` to change the names, date, family details, copy, map URL, asset paths, scratch threshold, or reveal timing. Colors and type styles are at the top of the page in the `:root` CSS variables.

## Assets

The five gallery photos are `assets/c1.jpg` through `assets/c5.jpg`. The supplied music is `assets/wedding-music.mp3.mp3`; it starts when the visitor taps the wax seal, and the music button remains available afterward.

For a hosted WhatsApp/Open Graph preview, set `og:url` to the public site address and use a fully qualified hosted `og:image` URL in `index.html`.
